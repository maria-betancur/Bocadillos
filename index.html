🚨 Solución al error "permission_denied"

Ese error significa que las reglas de tu base de datos Firebase están bloqueando el acceso. No es un problema del código: se arregla una sola vez en la consola de Firebase siguiendo estos pasos:

  1. Entra a console.firebase.google.com y abre tu proyecto degustase-1eb19.
  2. En el menú izquierdo elige Realtime Database (Base de datos en tiempo real).
  3. Arriba haz clic en la pestaña Reglas (Rules).
  4. Borra todo el texto que haya y pega las reglas de abajo.
  5. Pulsa el botón Publicar (Publish).
  6. Vuelve aquí y recarga la página, o pulsa "Guardar y Conectar".
{
  "rules": {
    ".read": true,
    ".write": true
  }
}

⚠️ Con estas reglas cualquier persona podrá leer y escribir el catálogo. Es lo habitual en catálogos públicos sin inicio de sesión.

🔥 Firebase (Base de Datos en Tiempo Real)

Para que el catálogo, los textos y colores se vean al instante en todos los dispositivos, ingresa la API Key y la Database URL de tu proyecto de Firebase. No agregues /datos a la URL.
